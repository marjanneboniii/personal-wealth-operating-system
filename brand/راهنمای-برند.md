# راهنمای هویت بصری برند «تراز» — TARAZ

نسخه ۱٫۰ — لوگوی اختصاصی برند تراز، هماهنگ با سیستم طراحی «Calm Ledger» اپلیکیشن.

---

## ۱. مفهوم

مارک «تراز» یک نشان انتزاعی و کاملاً اختصاصی است که از تلفیق دو مفهوم ساخته شده:

- **حرف «ت»** — نخستین حرف نام برند؛ تیرک افقی بالا همان سطرِ حرف «ت» است و دو نقطهٔ کناری، دو نقطهٔ همین حرف‌اند.
- **ترازو / تراز** — ستون میانی به‌همراه پایه، بدنهٔ یک تراز ایستاده را می‌سازد: نظم، تعادل و کنترل وضعیت مالی.

نشان از ۵ عنصر هندسی ساده ساخته شده (تیرک، ستون، پایه، دو نقطه) و در اندازهٔ کوچک نیز کاملاً خوانا می‌ماند. در نماد از هیچ عنصر کلیشه‌ای (دلار، سکه، کیف پول، نمودار و…) استفاده نشده است.

## ۲. مارک — ساختار و شبکه

- طراحی روی شبکهٔ ۶۴×۶۴ (پهنای جوهر ۴۹، ارتفاع جوهر ۲۴٫۵)
- ضخامت تیرک: ۵ واحد؛ ضخامت ستون: ۵ واحد؛ قطر نقاط: ۷ واحد
- پایه: میلهٔ کوتاه ۱۲×۴ واحد — نماد «پایداری و زمین‌گیری»
- فاصلهٔ نقاط از تیرک: ۳٫۵ واحد — هم‌خانواده با چیدمان نقطه‌های فونت وزیرمتن

### عناصر

```
    ●         ●        ← دو نقطه (نقاط حرف «ت»)
══════════════════════   ← تیرک (سطر ت / تیر ترازو)
         │               ← ستون میانی
         │
       ────              ← پایه (ثبات)
```

## ۳. کلمه‌نشان

- کلمه‌نشان «تراز» با فونت **وزیرمتن SemiBold** (همان فونت اپلیکیشن) نوشته شده است.
- فایل‌های SVG شامل مسیرهای برداری واقعی حروف‌اند — بدون وابستگی به نصب فونت روی سیستم بیننده.
- ترازبندی عمودی کلمه‌نشان نسبت به مارک با «مرکز نوری» حروف فارسی (با احتساب دنبالهٔ ر و ز) تنظیم شده است.

## ۴. لوگوهای ترکیبی

| حالت | توضیح |
|---|---|
| **افقی** (اصلی) | مارک سمت چپ، کلمه‌نشان سمت راست — هم‌جهت با خوانش راست‌به‌چپ |
| **عمودی (Stacked)** | مارک بالا، کلمه‌نشان زیر آن — مناسب Splash Screen و لندینگ |
| **مارک تنها** | برای آیکون اپ، فاویکون، آواتار و هدرهای کوچک |

## ۵. رنگ‌ها

رنگ اصلی برند، **آیریس** اپلیکیشن است (`#4C4EDB`) — نه سرمه‌ای تیره و نه طلایی. کلمه‌نشان در حالت روشن با «جوهر» (`#181B20`) و در حالت تیره با متن روشن (`#E9ECF1`) نوشته می‌شود.

| نام | مقدار | کاربرد |
|---|---|---|
| آیریس (Iris) | `#4C4EDB` | رنگ اصلی مارک |
| آیریس تیره | `#4042C4` | گرادیان تایل آیکون |
| آیریس روشن | `#8D8FF2` | مارک در پس‌زمینه تیره |
| جوهر | `#181B20` | کلمه‌نشان (حالت روشن) |
| کاغذ | `#F7F7F5` | پس‌زمینه روشن |
| سطح (کاشی) | `#F2F2EE` | کاشی آیکون روشن |
| شب | `#0C0E12` | پس‌زمینه تیره |
| متن تیره | `#E9ECF1` | کلمه‌نشان (حالت تیره) |

قانون: در پس‌زمینهٔ روشن از مارک آیریس و در پس‌زمینهٔ تیره از مارک آیریس روشن استفاده کنید. نسخهٔ تکرنگ (جوهر/سفید) برای چاپ و موارد محدود مجاز است.

## ۶. فضای امن (Clear Space)

حداقل فضای خالی دور لوگو برابر **ارتفاع خود تیرک** (تقریباً ۲۰٪ ارتفاع مارک) در هر چهار طرف است. هیچ عنصری نباید وارد این محدوده شود.

## ۷. حداقل اندازه

- مارک: ۱۶ پیکسل (فاویکون)
- لوگوی افقی: ۱۲۰ پیکسل عرض (هدر)
- لوگوی عمودی: ۹۶ پیکسل عرض (اسپلش)

## ۸. نکات استفاده

- لوگو را تغییر شکل، چرخش، کشیدگی یا تغییر رنگ ندهید.
- روی عکس‌ها و پس‌زمینه‌های شلوغ از نسخهٔ سفید یا تک‌رنگ استفاده کنید.
- بین مارک و کلمه‌نشان فاصلهٔ ثابت (۳۰٪ عرض مارک) حفظ شود.
- برای پس‌زمینهٔ تیره از فایل‌های `-dark` استفاده کنید.

## ۹. فایل‌ها

**برداری (SVG):**
- `logo-mark.svg` — مارک، آیریس (شفاف)
- `logo-mark-white.svg` / `logo-mark-mono.svg` / `logo-mark-soft.svg` / `logo-mark-alt.svg`
- `taraz-logo-horizontal.svg` + نسخهٔ تیره
- `taraz-logo-stacked.svg` + نسخهٔ تیره

**شطرنجی (PNG):**
- `app-icon-1024.png` (روشن) / `app-icon-dark-1024.png` (تیره) / `app-icon-iris-1024.png` (آیریس)
- `apple-touch-icon-180.png`، `app-icon-512/192.png`
- `favicon-16/32/48/64.png`
- `header-logo@2x.png` + تیره
- `splash-logo@2x.png` + پیش‌نمایش اسپلش (روشن/تیره)
- `wordmark-taraz.png` — کلمه‌نشان تنها
- `brand-board.png` — صفحهٔ معرفی کامل

**در اپلیکیشن (public/):**
- `icon.svg` — آیکون اپ (کاشی روشن + مارک آیریس)
- `favicon.svg` — فاویکون مرورگر
- `apple-touch-icon.png` — آیکون iOS
- `icon-192.png` / `icon-512.png` — آیکون‌های PWA

**توجه:** واریانت جایگزین `logo-mark-alt.*` نقطه‌ها را **بالای** تیرک دارد (هم‌سبک با نقطه‌های حرف «ت» در فونت وزیرمتن). نسخهٔ اصلی نقطه‌ها را پایین تیرک دارد (سبک کلاسیک فارسی).
