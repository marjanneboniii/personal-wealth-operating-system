# گزارش مختصر AUDIT — هویت کوتاه دارایی ملک (نام «سرای» + شناسه «1»)

**تاریخ:** ۱۴۰۵/۰۶/۰۳ (2026-08-25)

**دامنه:** املاک و هویت مشترک دارایی واقعی (`assets.symbol`، `assets.name`)

## نتیجه

- **نام دارایی** دیگر ترکیب بلند «آپارتمان — اهواز — شهرک دانشگاه» نیست. نام هر ملک اکنون **«سرای»** است: یک واژهٔ ۴ حرفی کوتاه و خلاقانه (نه تک‌حرف مثل «ت» یا «م») که در **تمام اپ** (ثبت، فهرست املاک، کارت ملک، دفترکل، سبد دارایی، ارزش‌ها و پیام‌های ثبت) یکسان نمایش داده می‌شود.
- شهر، محله و نوع ملک از نام حذف شده‌اند ولی **حذف نشده‌اند از داده** — همان‌طور که قبل از این هم در فیلدها/ستون‌های ساخت‌یافتهٔ Master Data (`cities`، `neighborhoods`، `property_types`) و ستون‌های مربوط به املاک نگهداری می‌شوند.
- **نمایش فارسی حذف شد:** ستون «نمایش فارسی» در جدول املاک و ردیف «نمایش فارسی» در کارت ملک و نگاشت قدیمی `RE-*` به نام فارسی (`display.ts`) حذف شدند. شناسه با رقم ASCII دقیقاً همان‌طور که ذخیره می‌شود نمایش داده می‌شود (`1`، نه `۰۰۱`).
- **شناسه کوتاه‌تر:** توالی مشترک RWA از `001` به کوتاه‌ترین شکل `1`، `2`، … تغییر کرد (بدون zero-padding). خودروها هم از همین توالی مشترک استفاده می‌کنند.

## کنترل‌های یکپارچگی

1. نام و شناسه همچنان ۱۰۰٪ توسط سیستم تولید می‌شود؛ هیچ ورود متن آزاد وجود ندارد.
2. شناسه یکتا و تغییرناپذیر است (Unique Constraint روی `assets.symbol`) و قفل ردیف کلاس RWA هنگام ثبت، توالی را سریالی می‌کند.
3. Migration `0009` ردیف‌های موجود را بدون برخورد با شناسه‌های اشغال‌شده بازشماره‌گذاری می‌کند (نگاشت collision-safe مشابه `0008`) و فقط `name`/`symbol` را تغییر می‌دهد.
4. **هیچ مبلغ، Posting، Lot، Snapshot نرخ ارز، تاریخچه ارزش‌گذاری یا سند دفترکل تغییر نمی‌کند.** مبالغ موجود فقط Identity هستند؛ دادهٔ مالی کاربر دست‌نخورده باقی می‌ماند.

## حریم خصوصی — بدون داده مالی واقعی

- هیچ عدد مالی «واقعی» کاربر در کد، دمو، Seed یا این گزارش ذخیره نشده است؛ اعداد نمونه در تست‌ها صرفاً مقادیر ساختگی/گرد هستند.
- Seed دمو فقط در `APP_MODE=development` یا `ALLOW_DEMO_SEED=true` و صرفاً روی پایگاه خالی اجرا می‌شود؛ در production هرگز اجرا نمی‌شود.
- Migration فقط Identity را بازنویسی می‌کند؛ مبالغ مالی کاربر حرکت نمی‌کنند و در فایل‌های repo کپی نمی‌شوند.

## استقرار و تأیید

```bash
npm run db:migrate
npm run typecheck
npm run test
```

آزمون‌ها پوشش می‌دهند: تولید نام «سرای»، شناسه `1`/`2`/…، حذف نمایش فارسی، و migration `0009` (بازشماره‌گذاری امن + عدم تغییر مبالغ).
