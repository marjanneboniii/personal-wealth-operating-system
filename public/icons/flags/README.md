# Currency flags

Round flat flags for the currencies on «نمای بازار», one file per ISO 4217
code (`USD.svg`, `EUR.svg`…). Source: [circle-flags](https://github.com/HatScripts/circle-flags)
v2.7.0 by HatScripts, MIT License. Stored locally so they load offline and
never change upstream. Rendered by `FiatMark` in
`src/components/ui/AssetTypeMarks.tsx`.
